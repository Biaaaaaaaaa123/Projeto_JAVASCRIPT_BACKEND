# Trilha de JavaScript - Alura

Este repositório reúne meus exercícios e exemplos desenvolvidos durante uma trilha de JavaScript da plataforma [Alura](https://www.alura.com.br/). Cada pasta representa uma aula, e os arquivos `.js` guardam práticas dos assuntos estudados.

## Organização

| Pasta | Conteúdos praticados |
| --- | --- |
| `aula1/` | Variáveis, números e escopo. |
| `aula2_ConhecendoArrays/` | Criação e manipulação de arrays, iteração, busca, filtros, ordenação, redução e cálculo de médias. |
| `aula3_Objetos/` | Criação e acesso a objetos, alteração de propriedades, métodos, iteração, ordenação, filtros e uso de dados JSON. |

Os arquivos são exercícios independentes. Para entender cada exemplo, abra o arquivo da aula correspondente e execute-o individualmente.

## Como executar

É necessário ter o [Node.js](https://nodejs.org/) instalado. No terminal, a partir da pasta do projeto, execute um arquivo pelo caminho relativo. Por exemplo:

```bash
node aula1/variaveis.js
```

Para executar outro exercício, substitua o caminho pelo arquivo desejado, por exemplo `aula2_ConhecendoArrays/calculo_media.js` ou `aula3_Objetos/objeto.js`.

## Objetivo

Este projeto funciona como um registro prático do meu aprendizado em JavaScript, organizado por aula e assunto. Os exemplos podem ser revisados e ampliados conforme avanço na trilha.
